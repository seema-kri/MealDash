
# 📑 MealDash — Project Documentation

This directory contains the business scoping, analytical reasoning, and stakeholder presentation materials for the **MealDash Delivery Operations Analytics** project.

---

## 📂 Documentation Files

| File | Type | Primary Audience | Description |
|---|---|---|---|
| **[`MealDash_BRD.pdf`](MealDash_BRD.pdf)** | PDF Document | Product & Analytics Leads | **Business Requirements Document:** Scopes the 10 core analytical questions, project constraints, data governance model, and success criteria. |
| **[`SQL_Report.pdf`](SQL_Report.pdf)** | PDF Document | Data Engineers & Analysts | **SQL Technical Findings Report:** Contains all 10 T-SQL queries, window functions, statistical validations, and confidence-level assessments. |
| **[`MealDash_Presentation.pptx`](MealDash_Presentation.pptx)** | Presentation Deck | Executive & Ops Leadership | **Leadership Slide Deck:** Concise slide-by-slide operational narrative summarizing the problem statement, pipeline architecture, and top recommendations. |

---

## 🎯 What These Documents Cover

* **Analytical Methodology:** How the operational question was broken into controllable operational levers (routing, staffing, bundling) versus non-controllable factors (weather).
* **Sample-Size Validation:** Complete transparency on statistical confidence (e.g., separating actionable findings in high-volume Metropolitan zones from small-sample noise in Semi-Urban zones).
* **Stakeholder Translation:** End-to-end translation from raw SQL aggregations into direct operational recommendations for operations managers and dispatch teams.
